# AI usage

## AI inside the product (runtime)

| Component | Model / service | Role | Can it decide facts? |
|---|---|---|---|
| Conversation composer | Google Gemini, three tiers via `backend/app/services/llm/router.py` (flash-lite, flash, pro) | Phrases replies from tool and rule results | No. Prices, stock and suitability come from deterministic code |
| Fallback composer | Rule-based templates (`services/composer.py`) | Used when Gemini is unavailable or over quota | No |
| Input guard | Regex patterns plus a Hugging Face DeBERTa prompt-injection classifier | Flags injection attempts before any model call | Only flags; it never answers |
| Retrieval | Gemini embeddings plus BM25, fused by reciprocal-rank fusion, stored in LanceDB | Finds catalogue passages for product questions | Supplies cited text only |
| Domain-adapted model | Qwen2.5-0.5B-Instruct with a LoRA adapter | Trained and evaluated offline; **not wired into the live chat** | n/a |

Every SKU and dollar amount in a reply is checked against tool results by the output guard.
Anything ungrounded is replaced by a template.

## AI used to build the project

- **Claude Code** assisted with the Design Studio front end (layout, per-surface visualizer,
  ledger, product photo wiring), the architecture diagram, the demo script, a unit test for the
  product-image endpoint, and the repository structure and documentation.
- **Synthetic training data** (`training/data/`) is generated by `training/generate_dataset.py`
  from the catalogue and business rules, not collected from real customers.

## Human responsibility

AI-generated code and text were reviewed and run before use: the test suite and the evaluation
runner are the acceptance checks, and the business rules (BR-01 to BR-10) are written and
maintained as plain Python so they do not depend on any model's behaviour.

## Data and privacy

- API keys live in `.env` (git-ignored); `.env.example` lists the names only.
- Product photos in `frontend/static/img/products/` must be images the project is allowed to use.
- No real customer data is used in training or evaluation.
